プーリー慣性を含むアトウッド加速度計算機

回転慣性を持つプーリーを介してつながった、2 つのつり下げ質量の加速度を計算します。 入力単位を選択し、指定された条件内で 1 つの値を計算します。

入力値

SI 単位への換算後に 0 より大きい値

SI 単位への換算後に 0 より大きい値

0 以上

SI 単位への換算後に 0 より大きい値

SI 単位への換算後に 0 より大きい値

計算はこのブラウザー内で行います。1.2e-3 などの指数表記に対応しています。桁区切り文字は使わないでください。

計算結果

質量 2 の下降を正とした加速度 a

—

値を入力し「計算する」を押してください。

公式

a = (m₂ − m₁)g / (m₁ + m₂ + I/r²)

適用条件

質量のない伸びないロープ、プーリー上で滑らない接触、自由に動くつり下げ質量を仮定し、軸の摩擦と空気抵抗を無視します。加速度が正なら質量 2 が下降し、負なら質量 1 が下降します。I=0 では慣性のない理想プーリーの極限になります。

表示値は浮動小数点数による近似値です。設計安全率や、入力されていない誤差要因は計算しません。
